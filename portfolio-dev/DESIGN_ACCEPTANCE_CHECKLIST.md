# Portfolio Design Acceptance Checklist — Production HQ 4
**Status:** Development-only; visual/brand approval pending. Last revised: 2026-11-12 Pacific.

## Owner rules
- [ ] Original photographs dominate the site; no generic AI-looking decoration.
- [ ] Sophisticated, restrained, timeless shapes, typography and color.
- [ ] Easy, obvious navigation; no mystery controls, hidden routes or dead ends.
- [ ] Every photo preserves natural proportions, original files and truthful captions.
- [ ] 63-photo editorial record and earlier designs remain intact; new originals added only with provenance.
- [ ] Completed work, proofs/artwork, equipment and history are clearly distinguished.
- [ ] Final RRR monogram/wordmark chosen and approved by the owner; current RR/ remains a placeholder.
- [ ] No publication, deployment, main-branch edits or merge without explicit approval.

## Design review disciplines (AI review perspectives, not separately retained human designers)
### Art direction
- [ ] Refine first-screen hierarchy: designer, commercial sign expertise and immediate gallery entry.
- [ ] Remove any visual flourishes that compete with photos.
- [ ] Inspect a side-by-side comparison against prior preserved candidate.
### Photography/editorial
- [ ] Select the strongest signature finished-work photographs for dominant placements.
- [ ] Confirm 51 selected / 12 archive visual hierarchy, image scale, overlap and captions.
- [ ] Inspect low-resolution originals and avoid stretching weak images.
### Brand/typography
- [ ] Use consistent type scale, spacing, color tokens, radius, borders and button treatments.
- [ ] Reserve a flexible neutral branding area for the future approved RRR artwork.
- [ ] Validate contrast, zoom and readable smallest text.
### Navigation/usability
- [ ] Test four-page menu, gallery categories, archive expand, viewer, keyboard, touch, and back to top.
- [ ] Confirm clear on-page onward routes without repeating excessive CTAs.
- [ ] Inspect layouts at 320, 375, 430, 768, 1024, 1440px, and 200% zoom.
### Engineering/release
- [ ] Consolidate accumulated competing CSS overrides before final signoff.
- [ ] Verify linked originals, lazy loading, image dimensions, layout shifts, reduced motion and focus states.
- [ ] Record actual browser-rendered screenshots, defects and retests.
- [ ] Present complete four-page final candidate for explicit approval before release.
