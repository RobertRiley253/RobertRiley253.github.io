## Instructions for uploading
1. Open the GitHub upload link for this folder.
2. Drag in the images or select "choose your files." Multiple files at once is fine.
3. Keep the branch set to `portfolio-editorial-material-review-2026-11-13`. Do **not** commit to `main`.
4. Finish with the GitHub **Commit changes** control. This stores the photos on the development branch without publishing them on the public site.
5. Let ChatGPT know when the upload is complete. The portfolio assistant will inventory, deduplicate, label, crop, and place them for owner review.

Suggested filenames: `tacoma-time-capsule-cover.jpg`, `washington-state-history-cover.jpg`, `time-vault-cover.jpg`, `puyallup-time-capsule-cover.jpg`, `70s-cover.jpg`, `80s-cover.jpg`.

Please avoid uploading credentials, private addresses, or other people's personal information. These repository files may be visible on GitHub even before the website is published.
